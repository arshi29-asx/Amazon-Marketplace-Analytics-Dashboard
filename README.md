# Amazon Marketplace Analytics Dashboard

## Overview

An interactive Amazon Marketplace Analytics Dashboard built in Power BI to analyze product performance, pricing trends, customer ratings, discounts, and category-level insights. The dashboard transforms raw e-commerce data into meaningful business intelligence through interactive visualizations and KPI tracking.

## Project Objective

To develop a comprehensive analytics dashboard that helps users understand product performance, customer behavior, pricing strategies, and category trends within an e-commerce marketplace.

## Dataset

The dataset contains information related to:

* Product details
* Product categories
* Actual and discounted prices
* Discount percentages
* Customer ratings
* Rating counts
* Product reviews
* Product links and images
